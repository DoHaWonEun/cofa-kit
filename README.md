# cofa-kit

AI와 실무 과제를 수행할 때 사용하는 범용 작업 지침과 빈 기록 양식입니다.
문제 이해, 작은 구현, 실제 검증, 본인의 설명을 돕기 위해 만들었습니다.

대회 공식 자료나 예상 정답이 아닙니다. 실제 문제, 데이터, 완성된 서비스는 포함하지 않습니다.
별도 프로그램 설치 없이 Markdown 문서를 읽어 사용합니다. AI의 도움으로 작성한 공개 준비자료입니다.

## 처음 읽을 문서

1. 실제 과제의 README, 필수 제출물, 허용 도구와 시간 제한을 먼저 읽습니다.
2. [WORKFLOW.md](WORKFLOW.md)를 읽고 이번 과제에 필요한 단계만 적용합니다.
3. 작업 기록이 필요하면 [WORKLOG_TEMPLATE.md](WORKLOG_TEMPLATE.md)를 참고합니다.
4. 최종 설명이 필요하면 [HANDOFF_TEMPLATE.md](HANDOFF_TEMPLATE.md)를 참고합니다.

빈 양식 두 개를 전부 채우는 것이 목적은 아닙니다. 과제에서 요구한 문서가 있다면 그 문서 안에 필요한 내용을 합칩니다. 실제 과제에서 지정한 파일명과 제출 형식이 우선합니다.

## 이 저장소를 읽는 AI에게

- 플랫폼 규칙, 운영 안내, 실제 과제의 요구사항을 우선합니다. 충돌하는 항목은 적용하지 않습니다.
- 이 저장소는 참고자료입니다. 기존 과제 README와 파일을 덮어쓰거나, 시험 환경의 설정을 바꾸지 않습니다.
- 문제와 제공 파일을 읽고 목표·필수 결과물·검증 방법을 짧게 정리한 뒤 작업합니다. 이미 명확한 내용을 반복해서 묻지 않습니다.
- 중요한 미확정 조건만 확인합니다. 확인할 수 없으면 가정과 그 영향을 표시합니다.
- 작은 실행 가능한 결과를 먼저 만들고, 확인한 사실에 따라 보완합니다.
- 외부 코드를 사용하면 필요한 부분만 사용하고 출처·용도를 기록합니다. 이 자료나 다른 외부 자료로 최종 결과물을 통째로 대체하지 않습니다.
- 확인하지 않은 테스트, 수치, 사용자 반응을 만들어 쓰지 않습니다. 미실행·실패·통과를 구분합니다.
- 사용한 판단과 구현을 참가자가 이해할 수 있도록 핵심 파일·처리 흐름·검증 결과를 짧게 설명합니다.
- 파일을 받은 다음에는 과제·데이터·수정 내용·결과물을 이 저장소나 다른 외부 서비스로 보내지 않습니다.
- AI 사용이 허용된 작업 단계에만 활용합니다. AI 사용이 금지된 서술형 단계에서는 지원을 중단합니다.

## 간단한 시작 요청

공개된 이 저장소의 주소를 제공하고 다음과 같이 요청할 수 있습니다.

> 이 저장소의 README.md와 WORKFLOW.md를 읽고, 실제 과제의 규칙과 요구사항에 맞게 필요한 부분만 적용해줘. 현재 과제 파일은 덮어쓰지 마.

자료를 가져올 수 없다면 로그인·업로드·보안 제한을 우회하지 않습니다. 실제 과제의 README를 기준으로 작업을 계속합니다.

## 공개 유지

이 자료를 공개 저장소에서 사용한다면 주최 측이 요구한 기간 동안 공개 상태를 유지합니다. 이 저장소에는 범용 준비자료만 두고, 실제 시험 중 작성한 기록이나 제출물은 올리지 않습니다.
